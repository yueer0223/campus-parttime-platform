# 校园兼职信息网

面向校园场景的兼职信息发布与接单平台，支持 PC 与手机浏览器响应式访问。

## 技术栈

- 前端：React 18 + Vite + TypeScript + React Router + ECharts
- 后端：Python 3.12 + FastAPI + SQLAlchemy 2.0 + SQLite + JWT
- AI：DeepSeek 大模型（阶段二接入）

## 角色

- 管理员：用户与任务管理、数据看板
- 发布者：发布兼职任务、AI 一键润色需求
- 接单者：浏览并接取任务

## 功能特性

- 三角色认证与权限（管理员 / 发布者 / 接单者）
- 任务发布审核、接单、完成、取消全流程
- AI 一键润色需求（DeepSeek，无 Key 时自动降级为本地规则）
- 数据看板（ECharts：状态分布、分类分布、发布趋势）
- 站内通知、任务评价、投诉处理、发布者与接单者私信
- 任务分页与无限滚动、骨架屏加载态
- 紫色鸢尾花主题，PC 与手机响应式

## 本地启动

后端：

```bash
cd backend
./.venv/bin/uvicorn app.main:app --reload
```

前端：

```bash
cd frontend
npm run dev
```

> 后端虚拟环境基于 Python 3.12.14（由 uv 安装的独立解释器）。

## 后续规划

以下能力当前未实现，作为后续迭代方向记录：

- **资金结算与平台抽成**：设计为"模拟托管"担保交易模式，任务发布时报酬托管到平台，完成后由管理员结算，平台按比例（建议 10%）抽成，接单者获得剩余部分。结算后记录资金流水，并在管理员看板展示平台累计收入、待结算金额等指标。因真实支付需企业资质，当前以模拟方式实现资金流闭环即可。
- **真实支付接入**：接入微信 / 支付宝支付，需商户资质与备案。
- **任务图片上传**：支持任务配图与用户头像。
- **消息实时推送**：私信当前为轮询刷新，可升级为 WebSocket 实时推送。
- **搜索与推荐**：更精细的筛选（报酬区间、时间、地点）与基于用户行为的任务推荐。
